# Конструктор публичных годовых отчётов для НКО

Веб-приложение, с помощью которого некоммерческая организация за 20–30 минут собирает
публичный годовой отчёт: заполняет формы, таблицы и загружает фотографии — и скачивает
готовый свёрстанный документ в PDF (формат А4, 6–7 страниц).

## Что умеет

- **6 разделов**: организация и миссия, показатели года, финансы (приход/расход),
  программы и проекты, фотографии (обложка + фоторепортаж), предпросмотр и PDF.
- **Свёрстанный PDF**: титульная страница с фото, сквозные колонтитулы и нумерация страниц,
  пронумерованные разделы, таблицы с шапками и итогами, диаграмма структуры расходов,
  карточки программ, цитата руководителя, страница партнёров, фоторепортаж, финальная страница.
- **Надёжный рендер**: локальные шрифты (Unbounded / Lora / Golos Text через @fontsource)
  и фотографии через CSS-фоны — в PDF всё попадает без искажений.
- **Демо-данные** фонда «Тёплый Север» — полный пример отчёта в один клик.
- **Автосохранение** в localStorage: черновик переживает перезагрузку страницы.
- Загрузка фото со сжатием, редактируемые таблицы, зум предпросмотра, тосты и модалки.

Все данные обрабатываются локально в браузере пользователя и никуда не отправляются.

## Стек

React 18 · TypeScript · Vite 6 · Tailwind CSS 4 · jsPDF · html2canvas-pro · JSZip · @fontsource

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # прод-сборка в dist/
npx vite preview   # локальный просмотр прод-сборки
```

## Размещение

Приложение полностью статическое — нужен только хостинг статики.

1. **Netlify Drop** — перетащить папку `dist/` на https://app.netlify.com/drop
2. **Vercel** — `npx vercel` (или импорт репозитория; framework: Vite, output: `dist`)
3. **Cloudflare Pages** — подключить репозиторий, build `npm run build`, output `dist`
4. **Свой сервер** — скопировать содержимое `dist/` в корень сайта

Для GitHub Pages в подкаталоге добавьте `base: '/имя-репозитория/'` в `vite.config.js`.

## Архив проекта

В шапке приложения есть кнопка **«Проект (ZIP)»** — она собирает все исходники
в архив `nko-annual-report.zip` прямо в браузере.

## Про демо-фотографии

Изображения демо-отчёта подгружаются по ссылкам из интернета. Если ссылка недоступна,
страницы отчёта используют аккуратные заглушки. Замените URL в `src/data/demo.ts`
на свои фотографии или data-URL.
