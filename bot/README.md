# Бот ВКонтакте + VK Mini App (Вариант Б)

Архитектура простая и надёжная:

```
Пользователь ВК ──пишет «отчёт»──▶ Бот (bot/index.js)
                                      │
                     кнопка-ссылка на мини-приложение
                                      ▼
              Мини-приложение = этот сайт (папка dist)
              пользователь заполняет отчёт и скачивает PDF
                                      │
                          присылает PDF боту
                                      ▼
                  Бот подтверждает и советует публикацию
```

Мини-приложение — это **точно этот же веб-проект**: при запуске внутри ВК он сам
определяет окружение через VK Bridge, показывает профиль пользователя в шапке,
скачивает PDF системным диалогом ВК и умеет открывать окно поста для сообщества.

## Шаг 1. Выложить сайт

```bash
npm install
npm run build
```

Затем перетащите папку `dist/` на https://app.netlify.com/drop — получите ссылку
вида `https://имя.netlify.app`. (Подойдёт и Vercel, и свой хостинг.)

## Шаг 2. Создать мини-приложение

1. Откройте https://id.vk.com (VK Developers) → **«Создать приложение»** → тип **«Мини-приложение»**.
2. В настройках приложения:
   - **URL приложения** — ваша netlify-ссылка;
   - **Доверенный домен** — домен из этой ссылки.
3. Привяжите приложение к сообществу НКО: сообщество → **Управление → Приложения →
   Подключить приложение** (или в настройках приложения — «Подключить к сообществу»).
4. Скопируйте ссылку приложения `https://vk.com/app12345678` — она понадобится боту.

Пользователи будут открывать конструктор прямо внутри ВК: в сообществе появится
вкладка с приложением, а бот сможет присылать кнопку-ссылку.

## Шаг 3. Токен для бота

В сообществе: **Управление → Работа с API → Создать ключ**.
Права: *сообщения*. Там же включите **Long Poll API** (события: входящие сообщения).

## Шаг 4. Запустить бота

```bash
cd bot
cp .env.example .env
# заполните VK_TOKEN и VK_MINI_APP_URL (ссылка вида https://vk.com/app…)
npm install
npm start
```

## Как это работает для пользователя

1. Пишет сообществу «отчёт» → бот отвечает кнопкой **«Открыть конструктор отчёта»**.
2. Заполняет пять разделов в мини-приложении, не выходя из ВК.
3. Скачивает PDF (кнопка «Скачать PDF» использует системный диалог ВК),
   при желании жмёт **«В сообщество»** — открывается окно поста, остаётся прикрепить файл.
4. Присылает PDF боту — бот подтверждает получение.

## Хостинг бота

Любой дешёвый VPS / Railway / Render: `node index.js` под `pm2` или системным
сервисом. Бот не хранит данные — только отвечает на сообщения.
